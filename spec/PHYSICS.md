# Scientific model and algorithm contract

## Scope and conventions
Educational 3D point mass, spherical rotating body, central gravity, simplified atmosphere, prescribed generic thrust orientation, event-aware integration; not 6DOF, CFD, structural design, certified guidance or proprietary flight reconstruction. For real rockets the public catalog is independent of generic scenario data. SI internally, radians, seconds, kg, newtons; UI converts km, t, degrees. Use double precision. State y=[rx,ry,rz,vx,vy,vz,p] with p remaining propellant of active serial stage. Inertial z is spin axis; no geographic targeting required; user can select body and generic scenario. Body radii and constants in vehicles.json. Reference position r in meters relative to body center. Render coordinates use camera-relative transforms, never change physics state. Spherical surface altitude h=norm(r)-R. Body-fixed position obtained by rotating inertial vector about z by -omega*t. Surface-relative velocity vrel=v-cross([0,0,omega],r) for co-rotating atmosphere, also usable in vacuum for surface motion. Speed=norm(v), vertical speed=dot(vrel,unit(r)), horizontal speed=sqrt(max(0,norm(vrel)^2-vertical^2)). For an initial point at equator use r=[R+h,0,0], v=[0,omega*(R+h),0] unless orbital initial state provided. Nonfinite/negative invalid quantities fail with explanation.

## Environment
Gravity a=-mu*r/norm(r)^3; optional disabled in analytic tests. Density and pressure in exponential mode rho=rho0*exp(-max(0,h)/H), P=P0*exp(-max(0,h)/H); stop at surface contact; above 150 km Earth or 100 km Mars set rho=P=0 (educational truncation, not real upper atmosphere). Moon vacuum. Exponential mode has no calculated sound speed unless constant temperature explicitly selected; Mach N/A. Mars approximation rho0=.020 kg/m3, P0=610 Pa, H=11100 m, T=210 K, gas constant 188.92 J/kg/K, gamma=1.29; fixed T for sound speed only. No local meteorology.

Earth layered option: approximation of US Standard Atmosphere 1976 through 84.852 km geopotential altitude. Hgeo=6356766*h/(6356766+h). Layer bases in m: [0,11000,20000,32000,47000,51000,71000,84852]; lapse rates K/m [-.0065,0,.001,.0028,0,-.0028,-.002]. Start T0=288.15, P0=101325, g0=9.80665, Rgas=287.05287, gamma=1.4. Precompute boundary T/P sequentially. For delta H, T=Tb+L*dH; if L==0 then P=Pb*exp(-g0*dH/(Rgas*Tb)), else P=Pb*(Tb/T)^(g0/(Rgas*L)). rho=P/(Rgas*T), speed of sound=sqrt(gamma*Rgas*T). Above model top use vacuum and mark 'outside lower atmosphere model'; document discontinuity. Do not market this as full USSA upper atmosphere. No Mach in vacuum.

## Dynamics
A=pi*(diameter/2)^2 unless explicit educational reference area. q=.5*rho*norm(vrel)^2. Drag acceleration=-.5*rho*Cd*A*norm(vrel)*vrel/m; zero when vrel zero. Cd constant unless user provides a table; interpolate between knots, clamp at ends, no extrapolation. If table is Mach-dependent and Mach unknown, use stated constant Cd fallback. Thrust F and specific impulse Isp define positive mass flow F/(Isp*g0). For generic stage endpoints use smooth pressure fraction alpha=clamp(P/101325,0,1), F=throttle*lerp(Fvac,Fsl,alpha), Isp=lerp(IspVac,IspSl,alpha). This is a simplified effective engine model; mass flow computed consistently at every evaluation; no claim to recreate actual engine. At zero throttle flow=0. Total mass=payload + active dry + p + wet mass of all future stages. dv/dt=gravity+drag+F*unitDirection/m. dr/dt=v; dp/dt=-massFlow. For vertical preset unitDirection=unit(r); for generic pitch demonstration use user-defined illustrative orientation interpolation, not actual vehicle control law. Staging subtracts discarded dry mass only after propellant depletion; do not add arbitrary momentum impulses. For ideal burn calculators delta-v=Isp*g0*ln(m_initial/m_final); for serial stages compute m_initial as total carried mass including future stages, m_final=m_initial-propellant burned, sum segment delta-v before discarding stage mass. If payload zero but carried dry positive equation valid; require all denominators positive. No flight path optimization or real-world guidance claims.

## Integrator and runner
RK4 step for fixed discrete mode: k1=f(t,y); k2=f(t+dt/2,y+dt*k1/2); k3=f(t+dt/2,y+dt*k2/2); k4=f(t+dt,y+dt*k3); yNext=y+dt*(k1+2*k2+2*k3+k4)/6. Recompute mass, environment and derivatives at each substage. Default dt=.1 s for ascent/descent, 1 s orbital demo, optional .02–5 s. Output every .5 s (ascent) or 5 s (orbit) via stepping exactly to output times. For depletion or ground crossing, bracket event and bisect within step by reintegrating from previous state, target time tolerance 1e-6 s; avoid invalid substep masses using positive dry floor and detect candidate crossings. At depletion set p=0, log event, switch stage with unchanged position/velocity and new mass; restart remaining timestep. At surface impact terminate, except initial pad state: if upward acceleration insufficient do not launch; display unable to lift. For orbit demo initialize circular velocity tangential sqrt(mu/r) or elliptical initial condition supplied. No ground contact at initialization if h=0 and outward acceleration. Cap run 2 million steps, 200k stored points; validate settings; worker cancel checked every 256 steps, progress every 200ms. Record actual event time; max q derived from samples with documented resolution, not prediction. Data can be decimated for graphics but export full samples. No arbitrary forced success. For stage visualization, event causes model separation; discarded stages can fade if no physical trajectory computed, label visualization only.

## Orbits and calculators
Specific energy E=dot(v,v)/2-mu/r; angular momentum H=cross(r,v); eccentricity vector e=cross(v,H)/mu-r/rnorm; eccentricity=norm(e); a=-mu/(2E) only when |E| outside tolerance; for bound e<1, rp=a*(1-e), ra=a*(1+e); altitude=radius-R. Period=2*pi*sqrt(a^3/mu) if bound and nonintersecting. Inclination=acos(clamp(H.z/norm(H),-1,1)), undefined for radial H~0. Circular velocity=sqrt(mu/r), escape=sqrt(2mu/r). If near-parabolic energy (relative tolerance 1e-10 of mu/r), no finite a or period. If rp<=R, classify intersecting, not orbit success. E>0 escape (if not already surface intersecting); distinguish instantaneous osculating orbit from future trajectory. RAAN/argument of periapsis undefined for singular configurations; use N/A rather than arbitrary angle. Orbital energy and H conservation computed in vacuum coast; relative errors compared against initial. Orbit definition uses inertial v, not surface velocity.

Hohmann transfer educational calculator between two circular coplanar orbits around same central body: at=(r1+r2)/2; dV1=sqrt(mu*(2/r1-1/at))-sqrt(mu/r1); dV2=sqrt(mu/r2)-sqrt(mu*(2/r2-1/at)); total absolute impulses; transfer time=pi*sqrt(at^3/mu). Earth-Moon/Mars display schematic only, not computed interplanetary mission timing. No ephemeris-backed windows in this release.

Additional calculators: thrust-to-weight F/(m*mu/r^2); burn duration propellantMass/massFlow for constant flow; mass ratio m0/mf; propellant fraction mp/m0; drag D=qCdA; gravity mu/r^2; pressure/density from selected atmosphere; ideal stage sum above; payload sensitivity via ideal equation on fixed generic stage; numerical error via actual test runs. Thermal educational pane explains qualitative speed/density dependence and displays kinetic energy per mass vrel^2/2; no quantitative heat flux without validated model, no temperature predictions. Recovery learning modes: generic parachute/drag demonstration with different educational CdA values, illustrative winged and tower-catch animations with no operational control law, propulsive/lunar/Mars descent as conceptual playback. Show limitations rather than fabricate real landing precision.
