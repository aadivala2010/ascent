# Agency art and geometry recipe

All profiles are VISUAL approximation recipes in meters, not manufacturing drawings or physical stage data. Origin at base, +Y upward, +Z forward, X lateral. A profile array lists [height,radius], revolve with 96 radial segments High, 48 Medium, 24 Low. Smooth nose curves via interpolated sample points, hard transitions preserve edges. Mesh groups: stage1, stage2, fairing, boosters, payload; apply actual event transforms only to supported generic configurations. Imported assets normalized to +Y, bounding box scaled to catalog height with aspect preserved, center x/z and base y=0. Use downloaded Saturn V/Shuttle when visually suitable; otherwise follow profiles below. Imported exterior read-only; procedural cutaways separate and explicitly schematic. Stage separation of real catalog-only entries is an exploded CAD illustration, not simulated flight. Do not add trademark logos unless permitted; plain name labels outside geometry.

## Custom generic vehicle
Height/diameter from preset or user, stage proportions from preset visual height fractions (sum <=1), remaining height fairing. Use LatheGeometry shell, separate rings, generic engine shapes. Section view uses clip plane and schematic tanks bounded within exterior; tank proportions are decorative unless calculated from user data; no actual tank volume claims. Explode stage groups by 0.18*height along Y; camera fits bounding box. Wireframe via material switch with edge overlay; dimension lines via projected world anchors and HTML labels. PBR shell metallic white .15 metalness/.45 roughness, black carbon .2/.65, steel .75/.32, orange foam .05/.8. Generate subtle deterministic scratches/normal map, no random change between sessions. Build simple modular launch pad using concrete plane, ring/base, truss tower using repeated cross-braced beams, floodlights, no exact site reproduction. Terrain visually schematic, no actual terrain claims.

## Performance
Stage groups reuse shared geometry/materials. Nozzle, grid, panel and tower repeated details instanced. Optional texture atlas. Limit hero vehicle to ~80k triangles High; imported models decimate only if supported without destroying silhouette; use LOD or simplify on weaker hardware. No more than 2 hero 3D canvases concurrently in comparison; dispose GPU resources on workspace change. Realistic mode uses the same world transforms as technical mode. Graphical quality is determined by the visible silhouette, materials, shadows, atmosphere and clear UI — not by downloading an unlimited number of polygons.
