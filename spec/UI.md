# Fixed UI decisions

Reference set 01–13 in reference-ui/ is the visual target. Use original ASCENT geometric SVG wordmark, not SpaceX logo; Inter/system sans plus IBM Plex Mono/system monospace, tabular figures. No decorative gradients; scientific colors allowed. CSS dark tokens: bg #08090A, surface #111315, elevated #191B1E, border #303338, text #F5F5F5, muted #A1A1AA. Light: #F4F5F6, #FFFFFF, #ECEEF0, #D4D7DB, #101214, #52565D. Buttons white/dark inverse, focus 2px outline, warnings use restrained semantic color + text. Corners 6px; border 1px; spacing 4/8/12/16/24px. Text sizes 12 metadata, 14 labels, 16 headers, 22–28 telemetry. All text contrast >=4.5:1 except large text >=3:1. Icon buttons 32px, input heights 32px; tooltip and accessible label. Fixed nav 56px, status 28px. Panel header 36px, internal padding 12px, row spacing 8px. Desktop target at 1920x1080; min 1024px with panels collapsible.

## Shell
Top: wordmark 180px, Mission Control, Vehicle Design, Mission Planning, Simulation, Analysis, Comparison, Laboratory, Documentation, theme, settings, fullscreen. Overflow nav at small width. Bottom: project, scenario status, body, graphics preset, actual FPS, local storage. No real-time launch data. Main 3D viewport fills remaining space. Default overlay panels left/right 300/340px with 12px outer gap; min 240px max 560px. Lower chart strip ~220px, timeline 72px when relevant. Keep central usable viewport >=40% width where possible. At 1280px use 248px panels, allow collapse; at 1024px only one default side open. Title bar drag handle, close/minimize, pin, maximize, resize edge/corner, dock target left/right/bottom; Dockview tab grouping. Persist per-workspace geometry in Dexie; clamp positions on resize; restore defaults. Keyboard Escape closes dialogs; focus trap; shortcuts disabled when typing. Motion: 180ms panel, 200ms theme, 900ms camera eased, reduced-motion immediate.

## Mission Control (01,12)
Planet full-canvas radius roughly 32% viewport height; default Earth, fixed illustrative Sun direction, rotatable body, day/night terminator, city lights only on night side. Left panels projects and saved scenarios with + New / open / duplicate / delete; right body facts and quick actions. Earth/Moon/Mars switch (top right), zoom/rotate/reset and optional latitude grid. Orbit traces only from actual saved runs; empty state says no runs. Status date is local simulation epoch, not live space tracking.

## Vehicle Design (02,03,04)
Center vertical vehicle on dark CAD grid or realistic neutral hangar. Left catalog list/search/filter (agency, era, simulation-ready vs catalog-only), stage/component tree. Right edit fields and computed mass/ideal performance; bottom tabs performance, mass breakdown, stage table. CAD toolbar solid, wireframe, cutaway, exploded, ortho front/side/top/bottom, isolate, measure, reset. Stage geometry is a group by stable stage ID; measurements report scene meters, not pixels. Imported model may use separate schematic cutaway if not separable; label. Parameter changes update custom geometry live, imported real models stay read-only until duplicated into generic configuration. Unknown data displays N/A; no precise performance estimate for incomplete entries. Simple mode: name, height, diameter, payload, number stages and generic defaults; advanced per-stage inputs from JSON schema. Validate before run.

## Mission Planning (05)
Left vehicle/body/scenario, initial-state selection, duration, atmosphere, numerical settings; center body-centric orbital plot/trajectory if available; right estimated ideal delta-v, orbital parameters, assumptions, Run Simulation. Bottom configuration and event list. Circular orbit and transfer calculators are educational; no fake date-specific launch windows. Show schematic/not to scale for multi-body diagrams. No manual piloting. Scenario templates: vertical ascent, ballistic coast, circular/elliptical orbit, generic multistage ascent, body-local descent, conceptual recovery.

## Simulation (06,07,09,10,12)
Center vehicle/planet scene, realistic/technical toggle, camera controls (follow, ground, distant, orbit, free), stage visualization and optional sound. Left elapsed time, altitude, speed, mass, stage status. Right trajectory, flight metrics, calculated events. Bottom timeline with run/pause/restart/seek/step and 0.25,1,5,10,100x playback; scrub interpolation uses actual data. Event markers show actual event times or explicitly predicted values. Conceptual recovery animations have persistent 'Illustrative demonstration — not a validated flight prediction' label and no pseudo-telemetry. Failure states explain numerical/physical reason. External vacuum audio muted; optional soundtrack toggle.

## Analysis (08)
Center orbit/trajectory pane upper 55%, chart dock lower 45%; left run selector and assumptions; right key results, export, validation summary. ECharts line charts with units, shared time cursor, tooltips, dataZoom, CSV/PNG. Chart variables altitude, speed, mass, thrust, q, drag, gravity, acceleration, orbital energy, periapsis/apoapsis only when defined. Never render arbitrary numbers for missing series. Report prints title, input snapshot, source confidence, methods, metrics and limitations.

## Comparison (11)
Left run selectors and parameter sweep inputs; center split synchronized viewports or trajectory overlay; bottom chart overlay solid/dash/dot with distinct labels; right difference table and parameter sweep progress/cancel. Compare actual run outputs, not manufacturer marketing payload ratings across unlike conditions. Absolute and percentage differences (N/A when baseline zero). No automatic claim of optimum without specified objective and constraints.

## Laboratory / Research / Documentation
Lab: two-column calculator list + equation/interactive fields/chart pane; each calculator shows symbols, units, assumptions, example and export. Learning tabs Mechanics, Propulsion, Atmosphere, Orbits, Recovery, Numerics, Validation. Research: title, question, hypothesis, variables, run links, notes, conclusions and source references; local save/export. Documentation: model limitations, verified-vs-synthetic legend, asset credits, actual test dashboard, creator and project page; no invented user credentials. All pages accessible in both themes.

## Rendering quality
Low 1K textures, 0.75 pixel ratio, 512 shadow, max 500 particles; Medium 2K, ratio <=1, 1024 shadow, 1500 particles; High 4K, ratio <=1.5, 2048 shadow, 4000 particles; Ultra 8K when GPU supports, ratio <=2, 2048–4096 shadow, 8000 particles. These are budgets, not measured benchmarks. Adaptive auto quality lowers rendering only after sustained slow frames; maintain physics timestep. Camera-relative world coordinates at orbital scale; local scenes in meters. Original procedural smoke billboards/instanced quads, emissive plume approximation, physically based materials, tone mapping, directional light and soft ambient. Reentry glow artistic unless explicitly linked to a documented model. No screenshot-as-background pretending to be 3D.
