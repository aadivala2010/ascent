# Engineering notebook

ASCENT includes a local research notebook in the Laboratory workspace with fields for:

- title;
- research question;
- hypothesis;
- observations and notes;
- conclusions;
- linked stored run IDs.

The fields intentionally start empty. ASCENT does not author a user's hypothesis, observations or conclusion. The notebook is stored in IndexedDB and remains on the current browser profile unless the user exports or clears it.

Recommended practice is to record the exact synthetic input, body, timestep, output cadence, solver version, assumptions and limitations before interpreting a comparison.
